# pair-wise-yf-49 法庭证据展示与庭审顺序控制

源提示词摘要：法官、书记员和双方代理人共同维护庭审证据目录，控制当前展示、证据顺序、敏感信息遮罩、计时、异议分支和庭审阶段；操作屏与公开屏分离，离线时仍可展示并能恢复本地快照。

## 技术栈

React19、TypeScript、Vite、Arco Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62014

## 断网暂存与回网字段合并

- 断网（右上角开关）时固化共同基线，之后的排序、敏感遮罩、备注/异议改动只进本地暂存，不整批回写。
- 回网走三路合并（base 断网快照 / local 暂存 / remote 法官目录）：
  - **排序、敏感遮罩、异议裁定**：各取最后改动（字段级时间戳 LWW）。
  - **已完成质证、裁定跳过**：确认状态锁定，整批回写也不回退。
  - 同一项在暂存和目录两侧都改且不一致：并列两版，书记员逐字段选定后才合并进目录；仅一侧改动自动并入。
  - 顺序变化时公开屏已确认画面在合并落盘后重算（版本号递增）；**合并完成前，涉敏感证据的备注不在公开屏出现**。

### 演示路径

1. 右上角切「本地恢复」断网 → 操作台上方出现「离线暂存中」面板。
2. 取消 e2 敏感遮罩、拖拽证据顺序、到「证据目录」页改 e1 备注（或在操作台支持 e2 异议）。
3. 点「模拟：法官断网期间在目录继续质证/改动」（e3 完成质证、e1 备注另改、e2 跳过并重新遮罩、重排顺序、支持异议）。
4. 点「回网并按字段合并」：查看自动合并项，对 e1 备注两版选定，确认后合并；公开屏显示「重算中」、敏感备注门控，落盘后按新顺序发布。
